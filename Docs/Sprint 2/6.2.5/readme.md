# US 6.2.5

## 1. Context

* Enable patients to login through the IAM.

## 2. Requirements

**US 6.2.5** As a Patient, I want to log in to the healthcare system, so that I can access my appointments, medical records, and other features securely.

## 3. Analysis

* The front end app should allow the patient to login/register.
* After login, the page should redirect to the patient menu with the patient options.
