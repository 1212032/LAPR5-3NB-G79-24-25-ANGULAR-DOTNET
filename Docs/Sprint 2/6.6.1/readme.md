## 4. Implementation

* Project Description and Functionalities:
  The system consists of a surgical and hospital resource management system with a focus on efficiency and GDPR compliance. It includes functionalities such as surgery scheduling, 3D visualisation of rooms and resource control, as well as measures to guarantee the security and privacy of personal data.

  * Main functionalities: Backoffice module to manage user profiles and bookings.
    3D Visualisation module to display room availability.
    Planning module to optimise surgery schedules.
    GDPR module to ensure compliance with data protection regulations.

* Identification of the Personal Data Processed: 
  The system will process personal data such as name, date of birth, contact details (email and telephone) and sensitive medical data such as patients' appointment history and allergies. It will also process data from healthcare professionals, such as licence number and availability of hours.

  * Data Classification: The system will use data classified as sensitive, for example: medical history, allergies, and data classified as non-sensitive, for example: name and contact details.

* Explanation of Data Processing Types:
  Data within the system will be collected during user registration, stored with encryption, accessed only by authorised professionals and if necessary updated or deleted in accordance with the GDPR.’ The System can collect, securely store, access, modify and delete data that is monitored and protected.

* Identification of the Legal Basis for Processing: 
  To ensure compliance, we have defined specific legal bases: we use consent for sensitive data such as medical history; legitimate interest for contact and appointments; and legal obligation for secure storage of medical records and audits.
  
* Data Breach Plan:
  In the event of a breach, our system will automatically detect the problem and immediately notify the affected users and the GDPR authority. The notification will include details of the breach, the corrective measures underway and recommendations for the user, such as resetting passwords. All incidents and subsequent actions will be recorded for auditing and continuous improvement of the system.

* Reinforcing Professionalism: 
  With this system, we are committed to providing a solution that not only meets the customer's needs in terms of functionality and efficiency, but also ensures that all personal data is handled with the highest level of security and respect for privacy.
