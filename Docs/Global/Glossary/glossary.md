## Glossary

## Glossary

| **Term**                        | **Definition**                                                                                                                                           |
|---------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| Appointment status              | Scheduled, Completed, Canceled.                                                                                                                        |
| Elective Surgery                | A planned procedure that is not life-threatening and can be scheduled at a convenient time (e.g., joint replacement, cataract surgery).                |
| Emergency Surgery                | Needs immediate intervention to save life, limb, or function. Typically performed within hours (e.g., ruptured aneurysm, trauma).                      |
| Operation request priority      | Elective Surgery, Urgent Surgery, Emergency Surgery.                                                                                                   |
| Operation type estimated duration| Total duration time of all the operation procedures (e.g. Anaesthesia/patient preparation, Surgery, Cleaning).                                         |
| Operation type                  | A specific medical procedure, defined by name, staff and estimated duration.                                                                           |
| Surgery room status             | Available, Occupied, Under maintenance.                                                                                                                |
| Surgery room type               | Operating room, Consultation room, ICU.                                                                                                               |
| Urgent Surgery                  | Needs to be done sooner but is not an immediate emergency. Typically within days (e.g., certain types of cancer surgeries).                             |
| User role                       | Admin, Doctor, Nurse, Technician, Patient.                                                                                                             |
| User                            | Represents a user in the system, either an admin managing the system, a healthcare staff (e.g. doctor, nurse, technician) or patients interacting with it. |
| Patient profile                 | A record containing a patient's personal and medical information, including name, contact information, medical history, and demographic data.         |
| Medical Record Number           | A unique identifier assigned to each patient, generated in the format YYYYMMnnnnnn, where YYYY is the year, MM is the month, and nnnnnn is a sequence number. |
| System Change Log               | A record of changes made to patient profiles, including what was changed, the old and new values, and who made the change.                             |
| Gender                          | Represents the gender of a patient (e.g., Male, Female, Non-Binary) and is used to ensure proper identification and treatment.                        |
| Consent                         | The process by which patients agree to the handling of their personal data and to receive communication from the healthcare provider.                   |
| Privacy Policy                  | A document outlining how the healthcare provider handles personal data, including user rights under regulations like GDPR.                              |
| GDPR                            | General Data Protection Regulation; a regulation in EU law on data protection and privacy.                                                             |
| Email Verification              | The process of sending a confirmation email to a user to verify their identity during registration or account recovery.                                  |
| Identity Management System (IAM) | A framework for managing user identities and access rights within the application, allowing for secure authentication and authorization.               |
| Role-Based Access Control (RBAC) | A method of regulating access to computer or network resources based on the roles of individual users within an organization.                         |
